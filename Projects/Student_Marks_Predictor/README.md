# Student Marks Predictor

## About
A beginner Machine Learning project that predicts a student's current exam marks using study hours and previous marks.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Features
- Loads and analyzes student data from a CSV file.
- Visualizes study hours and current marks.
- Trains a Linear Regression model.
- Evaluates predictions using Mean Absolute Error (MAE).
- Predicts marks for a new student based on user input.

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn
```

Run the Python file:

```bash
python main.py
```

## Learning Goals
Practice data analysis, data visualization, model training, evaluation, and prediction using Python.
